# Apex AI — Race Engineer

Prototyp webowy do analizy jazdy w Assetto Corsa Competizione.

- [Uruchom dashboard Apex AI](https://sergiosochanskiracingpoland-dotcom.github.io/apex-ai/)
- [Rejestrator ACC na Windows 11 — instrukcja](acc_collector/README.md)

Wersja webowa działa w przeglądarce. Do zbierania rzeczywistej telemetrii użyj lokalnego rejestratora, a następnie zaimportuj pliki `*_laps.csv` i `*_samples.csv` do dashboardu. Import surowej telemetrii działa od 0.2.8, a od **0.2.9** dashboard pokazuje wykres prędkości wybranego okrążenia. Wykresy gazu i hamulca powstaną w kolejnych aktualizacjach. Pliki są przechowywane na Twoim komputerze. Konsultacje z prawdziwym modelem AI i komunikacja głosowa na żywo są planowane na później.

**Status:** eksperymentalny kod rejestratora; wymaga testu z uruchomionym ACC.
